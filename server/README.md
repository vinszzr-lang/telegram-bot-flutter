# ChatWithU Node.js Backend

Pterodactyl-friendly Node.js + Express + Socket.IO backend.

Start:

```bash
npm install --omit=dev
node index.js
```

Environment variables:

```text
PORT=5201
PUBLIC_BASE_URL=http://malzoffc.pterocloud.my.id:4872
JWT_SECRET=replace-me
```

Health check:

`GET /health`
