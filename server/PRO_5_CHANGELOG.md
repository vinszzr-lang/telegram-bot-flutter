# ChatWithU Server 5.0 PRO

## Stability
- Idempotent send with clientMessageId.
- Send/login/register rate limiting.
- Atomic JSON database saves.
- Graceful shutdown.

## Chat
- Reply metadata for text/media/file/sticker.
- Edit text messages.
- Reactions.
- Pin/unpin.
- Pinned message lists.
- Existing block/contact/read/presence/typing support retained.

## Groups
- Same media pipeline as private chat.
- Reply/media/sticker/file support retained.
- Polls with one vote per account.
- Group admin pin permissions.
- Group moderation/member controls retained.

## Admin
- Pro Command Center styling retained and extended.
- System Live page.
- Runtime, memory, online, message, storage metrics.
- Backup/export/user/message moderation tools retained.
